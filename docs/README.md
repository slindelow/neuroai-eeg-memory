# Documentation

- [Research report](REPORT.md) explains the data work, model construction, evaluation, result,
  limitations, and learning.
- [Research decisions](RESEARCH_DECISIONS.md) records the selected designs and rejected
  alternatives.
- [Failures and fixes](FAILURES_AND_FIXES.md) shows how pipeline failures changed the final
  safeguards.
- [Analysis Charter](analysis-charter-m1-v1.md) preserves the frozen scientific specification.
- [ROI map](roi-map-m1-v1.md) records the reproducible sensor-space translation.
- [References](references.md) contains the scientific and methodological source record.

The JSON files are machine-readable contracts used by the implementation and tests. Private human
receipts, participant-level predictions, raw EEG, and local execution paths are intentionally not
published. The public manifest generator therefore validates the frozen scientific contracts but
does not reproduce the private receipt gate.
